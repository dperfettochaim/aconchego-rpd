# Aconchego

Aplicativo Android de registros de pensamentos (RPD), com funcionamento offline e exportação em PDF.

Interface acolhedora em vermelho e laranja, formulário por etapas, busca e edição de registros. Os dados ficam no próprio aparelho.

Veja LEIA-ME.md para compilar. O workflow Android gera o instalador APK nos artefatos do GitHub Actions.
